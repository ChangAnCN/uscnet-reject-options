# Reject options under class imbalance in chest radiography

Code for a controlled comparison of reject-option designs (confidence scores,
selection policies, LABEL conformal abstention, SelectiveNet and a
class-balanced SelectiveNet objective) on ChestX-ray14 and CheXpert, with
class-resolved coverage and four class-averaged risks (balanced error on the
accepted subset, generalised risk, CA-AURC, CA-AUGRC).

This repository contains the pipeline and analysis code only. Model
checkpoints, cached predictions, result tables, figures and the manuscript
are not included; every reported number can be regenerated by running the
pipeline below.

## Layout

```
src/
  common.py               labels, dataset cache, model definition
  prep_data.py            ChestX-ray14: labels, patient-disjoint split (asserted), 256 px cache
  prep_chexpert.py        CheXpert external cohorts (blank label = absent, uncertain excluded)
  train.py                DenseNet121, 14 findings, one seed per call
  infer.py                deterministic + MC-dropout predictions for every cohort
  selective.py            scores, calibration, risk-coverage utilities, cue bank, bootstrap
  imbalance_selective.py  class-resolved coverage, the four class-averaged risks,
                          global / class-conditional / LABEL selection rules
  backbone_eval.py        per-finding AUROC against published baselines
  analyze.py              per-seed selective analysis, external cohorts
  boot_compare.py         case-level bootstrap of ranking-rule comparisons
  train_selectivenet.py   SelectiveNet (weighted / unweighted) and CB-SelectiveNet
  benchmark.py            the score x policy grid, LABEL, SelectiveNet variants
  robustness.py           threshold rules, cost ratio, case-level and seed x case bootstraps
  cue_association.py      symmetric vs signed cue scores, within-class associations
  ca_robustness.py        CA metrics under three integration ranges
scripts/
  setup_env.sh            conda environment (PyTorch cu128 for compute capability 10.0)
  dl_cxr14.py, dl_chexpert*.py, extract.sh   dataset download / extraction
  run_train.sh, run_pipeline.sh, run_selectivenet.sh, run_cbselectivenet.sh, run_revision.sh
tests/
  test_selective.py, test_imbalance.py       metric implementations against hand computations
```

## Paths

All scripts assume a working root of `/NHNHOME/uscnet` with `data/`, `ckpt/`,
`results/` and `logs/` beneath it (the machine this was developed on keeps
the large files on a separate volume). Create that directory or symlink it
to your own location before running anything.

## Data

* ChestX-ray14 (CXR8): HuggingFace `alkzar90/NIH-Chest-X-ray-dataset`, which
  ships the official `train_val_list.txt` / `test_list.txt` partition.
* CheXpert: HuggingFace `danjacobellis/chexpert`. The train partition gives
  the external cohort; the 234-image official validation partition is kept
  separately as an underpowered radiologist-labelled check.

Both are used under their original licences; no images are redistributed.

## Pipeline

```bash
bash scripts/setup_env.sh
python scripts/dl_cxr14.py && python scripts/dl_chexpert_full.py && bash scripts/extract.sh
cd src
python prep_data.py && python prep_chexpert.py
for s in 42 123 3407 7 2024; do python train.py --seed $s --epochs 15; done
python infer.py --cohorts val test chexpert_expert --n_mc 20
python infer.py --cohorts train --n_mc 2
python infer.py --cohorts chexpert_ext --n_mc 20
python backbone_eval.py
python analyze.py
python boot_compare.py
bash ../scripts/run_selectivenet.sh      # SelectiveNet, weighted + unweighted
bash ../scripts/run_cbselectivenet.sh    # CB-SelectiveNet
bash ../scripts/run_revision.sh A; bash ../scripts/run_revision.sh B   # unweighted on effusion; lambda/2
python benchmark.py --targets Pneumonia Effusion --selectivenet
python robustness.py
python cue_association.py
python ca_robustness.py
```

Hardware used: one NVIDIA B200; training one seed takes about 20 minutes,
the full pipeline a few hours.

## Metrics

* **Class-resolved coverage**: fraction of each true class still answered at
  a matched overall coverage; disparity = negative minus positive coverage.
* **Balanced error on the accepted subset** (area: AURC) and **generalised
  risk** with whole-class denominators (AUGRC), both at matched overall
  coverage on a 20-100% grid.
* **CA-AURC / CA-AUGRC**: each class's risk integrated against that class's
  own realised coverage, averaged over classes (`ca_robustness.py` repeats
  this on a 2-100% sweep and on a common 50-100% window).
* **Within-class AURC**: each class's own cases ranked by the score over a
  common class-coverage grid.

Nothing is fitted on test data: temperature, operating threshold (Youden's
J), cue threshold, normalisers, fusion weights and conformal quantiles are
all fitted on the validation split of the same seed.
